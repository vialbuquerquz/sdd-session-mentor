# Rubrica de avaliação do prompt

Pontue cada critério de 0 a 2 e justifique com um trecho do prompt.
0 = ausente, 1 = parcial, 2 = bem feito. Total máximo: 12.

| # | Critério | 2 pontos quando... |
| --- | --- | --- |
| 1 | Clareza do objetivo | Diz exatamente o que deve existir ao final, sem ambiguidade |
| 2 | Contexto e ancoragem na spec | Cita a spec, requisito ou tarefa (ex.: `FR-003`, `T012`) e os arquivos relevantes |
| 3 | Escopo adequado | Cabe em uma entrega revisável; não mistura várias tarefas |
| 4 | Critério de aceite / verificação | Diz como saber que está pronto (teste, comportamento esperado, exemplo) |
| 5 | Restrições técnicas | Explicita o que não pode mudar, padrões, stack, limites |
| 6 | Aderência à fase SDD | O pedido é próprio da fase atual (não pula etapas) |

## Faixas

| Total | Nível | Leitura para o aluno |
| --- | --- | --- |
| 11–12 | Exemplar | Pode virar modelo para a equipe |
| 8–10 | Sólido | Funciona; pequenos ajustes deixariam o resultado mais previsível |
| 5–7 | Em desenvolvimento | O Claude precisou adivinhar partes importantes |
| 0–4 | Frágil | Alto risco de retrabalho; reescreva antes de enviar |

## Como apresentar no registro

Use uma tabela com as colunas Critério | Nota | Justificativa, seguida da linha de total
e do nível. Para critérios que não se aplicam (ex.: restrições técnicas numa dúvida
conceitual), dê 2 e escreva "não se aplica" para não punir o aluno injustamente.
